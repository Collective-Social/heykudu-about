# GitHub Proof-of-Work Analysis Skill

## Purpose
Turns everyday software engineering commits and PR merges into high-credibility proof-of-work marketing content.

## Ingestion Workflow
1. **Commit & PR Parsing**:
   - Parse commit headers (`feat:`, `fix:`, `perf:`, `refactor:`, `migration:`).
   - Extract files changed (e.g., GPS geofencing, NFC check-in, WBA PDF generation, offline sync).
2. **Value Translation**:
   - *Technical action*: "Added Haversine GPS radius check with 150m accuracy threshold."
   - *Commercial value*: "How we eliminated ghost attendance in high-rise academic hospital wings with micro-geofencing."
   - *Technical action*: "Implemented WBA Mini-CEX multi-signature export with cryptographically signed PDF."
   - *Commercial value*: "Replacing 3-ring binder HPCSA audit inspections with 1-click verified PDF portfolios."
3. **Trigger Threshold**:
   - Every merge into `main` automatically creates a new Campaign draft with technical proof points pre-populated.
